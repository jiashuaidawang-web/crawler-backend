# 2026-08-22 同花顺 L2 数据捕获 — TLS 证书固定问题

## 问题现象
- App 连接 mitmproxy 代理但拒绝证书：`Client TLS handshake failed. The client does not trust the proxy's certificate`
- 证书已安装到系统存储（bind mount），但 App 仍不信任

## 根因分析
1. **App 使用自研 SSL 库 `libhssl-2.1.so`** — 证书固定发生在原生层（Native Layer）
2. **加固壳 `libjiagu.so`** — 导致 Frida spawn 模式崩溃
3. **networkSecurityConfig 使用默认信任锚点** — 没有 explicit trust-anchors 配置
4. **Android 12 强制要求 v2 签名** — `jarsigner` 只支持 v1，无法安装修改版 APK

## 已尝试的方法

| 方法 | 结果 | 原因 |
|------|------|------|
| bind mount 安装系统证书 | ❌ | 证书可见但 App 不信任（原生层固定） |
| 修改 APK networkSecurityConfig | ❌ | v2 签名问题（jarsigner 只支持 v1） |
| 手动 Python v2 签名 | ❌ | 签名格式不被 Android 识别 |
| Frida spawn 模式 | ❌ | 需要 frida-gadget（无法下载） |
| Frida attach 模式 | ❌ | "unable to connect to remote frida-server: closed" |
| Frida native hook | ❌ | 同上 |
| 下载 apksigner/zipalign | ❌ | 所有镜像源被阻止 |
| 下载 frida-server/gadget | ❌ | GitHub/npm/镜像源均不可用 |

## 关键发现
- `libhssl-2.1.so` — 同花顺自研 SSL 库，证书固定在此层
- `libjiagu.so` — 梆梆加固壳，反调试
- APK 中没有 `network-security-config` 字符串（使用默认配置）
- 模拟器无 Magisk/KernelSU

## 关键排查经验
1. **检查 APK 的 SSL 实现** — `unzip -l apk | grep lib.*ssl` 或 `grep -r "\.so" apk/`
2. **检查 networkSecurityConfig** — 如果没有 explicit trust-anchors，使用默认配置
3. **检查加固壳** — `libjiagu.so` = 梆梆加固，`libsecexe.s` = 爱加密
4. **Android 12+ 需要 v2 签名** — `jarsigner` 不够，需要 `apksigner`
5. **Frida attach 需要 frida-server 版本匹配** — CLI 17.x 需要 server 17.x
