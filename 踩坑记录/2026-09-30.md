# 2026-09-30 构建失败：maven.compiler.release=21 但 PATH java 是 JDK 8

## 问题现象

`mvn package -pl crawler-worker -am -DskipTests` 编译失败，报 Lombok 注解未生效：
- `找不到符号: 方法 getTaskType()`（EastmoneyEndpoints.EndpointSpec）
- `找不到符号: 方法 getTask()`（CrawlContext）
- `找不到符号: 方法 setStrategyConfig()`（CrawlContext）
- `找不到符号: 方法 setSuccess(boolean)`（CrawlResult）
- 等等几十个 Lombok 生成的方法找不到

## 根因

`pom.xml` 设置了 `<maven.compiler.release>21</maven.compiler.release>`，但系统 PATH 中的默认 `java` 是 JDK 8（`D:\Development\Environment\Jdk\JDK8_202`）。

Maven compiler plugin 3.11.0 在 JDK 8 的 javac 上不支持 `--release 21` 参数，导致：
1. 编译时 Lombok 注解处理器无法正常运行
2. `@Data`、`@AllArgsConstructor` 等注解不生成代码
3. 所有依赖 Lombok 生成方法的代码全部报错

## 修复

使用 JDK 21 编译：
```bash
export JAVA_HOME="D:/Development/Environment/Jdk/jdk-21.0.11"
mvn.cmd -pl crawler-worker -am package -DskipTests
```

> **关键**：`mvn.cmd` 是 Windows batch 文件，它读取 `JAVA_HOME` 环境变量。Git bash 中 `export PATH` 后 `java -version` 仍显示 JDK 8，但 `mvn.cmd` 内部用 `JAVA_HOME` 定位 JDK，不受 Git bash PATH 影响。

## 关键排查经验

**Maven 编译报 Lombok 方法找不到，首先检查 JDK 版本是否匹配 `maven.compiler.release`**。`release=21` 要求 JDK 9+，JDK 8 的 javac 不支持该参数，Lombok 注解处理器会静默失败。
