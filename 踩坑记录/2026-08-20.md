# 2026-08-20 日批跑全线失败:青果代理 API Key 过期

## 问题现象

日批编排 17 个阶段仅 STOCK_DAILY(股票日线)跑出 5552 行,其余 16 个阶段:
- 7 个 SKIP(地域/行业/概念日线、个股/板块主力资金流、龙虎榜明细、板块基础):提示"无上游总数"
- 8 个 DONE 但写入 0 行(涨停/跌停/炸板/强势/次新股池、指数日线、龙虎榜、北向资金)
- 1 个 PENDING(股票周线)

## 根因(按影响排序)

**根因 1(主要):Admin 青果代理 API Key 过期,探测全失败。**

`SeedStrategyBeans.java:21` 硬编码了青果凭证 `("2D4620A7", "NM8XFDR2", "22574E11640D")`,其中 `2D4620A7` 已失效:

```bash
$ curl "https://share.proxy.qg.net/get?key=2D4620A7&..."
{"code":"INVALID_KEY","message":"Key不存在或已过期"}
```

故障链:
1. admin 提取代理 → `QgLongTermProxyProvider.acquire()` 拿 HTTP 400 → 返回 null
2. `ProxyManager` 10 次重试全失败(`logs/info.log` 满屏 `[acquireProxy] provider 返回 null`)
3. 所有阶段上游探测(`fetchClistTotalByProxy`/`fetchPoolTotalByProxy`/`fetchDragonTigerCount`)无代理可用 → 返回 -1
4. `seedClistTypeSingleResult` 等探测 ≤0 → 返回 `SeedResult(0, 0, ...)` → 阶段被跳过

Worker 用的是 `application.yml` 里另一套凭证(`NM8XFDR2`/`7pabvimp`/`22574E11640D`),还能用,所以 STOCK_DAILY 靠 worker 跑通。

**根因 2(次要):Admin 硬编码代理凭证,与 worker 双份配置易漂移。**

Admin 在 `SeedStrategyBeans` 写死 key,worker 在 `application.yml` 的 `proxy.qg.*`。两处各自维护,一旦某处过期另一处无感知,排查时容易漏掉 admin 侧。

## 修复

**已执行(待部署):**

1. `crawler-admin/src/main/resources.application.yml:75-82` 新增 `proxy.qg.*` 配置段,填入可用凭证(与 worker 一致):
   ```yaml
   proxy:
     qg:
       auth-key: NM8XFDR2
       business-id: 7pabvimp
       password: 22574E11640D
   ```

2. `crawler-admin/.../seed/SeedStrategyBeans.java:20-22` 改为注入 `QgLongTermConfig` 读配置,删除硬编码:
   ```java
   @Bean
   public ProxyProvider qgProxyProvider(QgLongTermConfig qgConfig) {
       return new QgLongTermProxyProvider(qgConfig.getAuthKey(), qgConfig.getBusinessId(), qgConfig.getPassword());
   }
   ```
   `QgLongTermConfig` 原本已存在(`@ConfigurationProperties(prefix="proxy.qg")`)但未启用,现在真正接上。

编译验证:`mvn compile -DskipTests` 通过。

## 关键排查经验

**日批大面积空跑/零行,先看 admin 代理是否通。** 编排器所有阶段都依赖 admin 侧的"上游探测"获取 expectedTotal,而探测走 `ProxyManager`(青果)。一旦 admin 拿不到代理,全部阶段探测返回 -1 → 全跳 0 行。worker 的代理是另一套(独立 `WorkerProxyManager`),worker 能跑 ≠ admin 能探测。

**排查命令:**
```bash
# 直接测青果 API 是否有效
curl "https://share.proxy.qg.net/get?key=<AUTH_KEY>&num=1&format=json&distinct=true"
# 有效 → {"code":"SUCCESS",...}  ; 过期 → {"code":"INVALID_KEY",...}
```

**踩坑索引:**

| 坑 | 影响 | 修复状态 |
|---|---|---|
| 青果 API Key `2D4620A7` 过期 | admin 探测全失败 → 16 阶段空跑 | 已换可用 key `NM8XFDR2`,待部署 |
| admin 硬编码代理凭证 | 与 worker 双份配置漂移无感知 | 已改读 `application.yml`,待部署 |
