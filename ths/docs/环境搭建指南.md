# 同花顺资金流向爬虫 - 环境搭建指南

## 目标
在全新 Windows 或 Linux 电脑上，从零搭建可运行的同花顺资金流向爬取环境。

---

## 一、Windows 搭建

### 1. 安装依赖

#### Python 3.8+
- 下载地址: https://www.python.org/downloads/
- 安装时勾选 "Add Python to PATH"

#### Node.js 16+
- 下载地址: https://nodejs.org/
- 需要 Node.js 是因为 token 获取需要执行 chameleon JS

#### 验证安装
```bash
python --version
node --version
npm --version
```

### 2. 获取项目

```bash
git clone <项目地址>
cd crawler-backend/ths/crawler
```

### 3. 安装 Python 依赖

```bash
pip install -r requirements.txt
```

### 4. 安装 Node.js 依赖（用于 token 获取）

```bash
cd ths/crawler
npm install jsdom
```

### 5. 配置 ClickHouse 连接

编辑 `config.py` 或设置环境变量：

```bash
# Windows CMD
set CK_HOST=100.97.74.45
set CK_PORT=9000
set CK_DB=crawler
set CK_USER=default
set CK_PASS=pamirs@123

# Windows PowerShell
$env:CK_HOST="100.97.74.45"
$env:CK_PORT="9000"
```

> ⚠️ **重要**: clickhouse-driver 使用原生协议，端口必须是 **9000**（不是 8123）

### 6. 运行

```bash
# 抓取全部
python main.py

# 只抓某类
python main.py --type industry
python main.py --type stock
python main.py --type lhb
python main.py --type north

# 指定日期
python main.py --date 2026-08-22

# 限制页数（测试用）
python main.py --type stock --pages 2
```

## 二、Linux 搭建

### 1. 安装依赖

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install -y python3 python3-pip python3-venv nodejs npm

# CentOS/RHEL
sudo yum install -y python3 python3-pip nodejs npm
```

### 2. 创建虚拟环境

```bash
cd ths/crawler
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. 安装 Node.js 依赖

```bash
cd ths/crawler
npm init -y
npm install jsdom
```

### 4. 配置环境变量

```bash
export CK_HOST=100.97.74.45
export CK_PORT=9000
export CK_DB=crawler
export CK_USER=default
export CK_PASS=pamirs@123
```

> ⚠️ **重要**: clickhouse-driver 使用原生协议，端口必须是 **9000**（不是 8123）

### 5. 运行

```bash
python main.py
```

### 6. 配置定时任务（crontab）

```bash
# 每天 16:00 抓取
crontab -e
# 添加:
0 16 * * * cd /path/to/ths/crawler && /path/to/venv/bin/python main.py >> /var/log/ths_crawler.log 2>&1
```

## 三、Docker 搭建（跨平台通用）

### Dockerfile

```dockerfile
FROM python:3.11-slim

# 安装 Node.js
RUN apt-get update && apt-get install -y curl gnupg
RUN curl -fsSL https://deb.nodesource.com/setup_18.x | bash -
RUN apt-get install -y nodejs

WORKDIR /app

# Python 依赖
COPY crawler/requirements.txt .
RUN pip install -r requirements.txt

# Node.js 依赖
COPY crawler/ .
RUN npm init -y && npm install jsdom

CMD ["python", "main.py"]
```

### 构建运行

```bash
docker build -t ths-crawler .
docker run --rm \
  -e CK_HOST=100.97.74.45 \
  -e CK_PORT=9000 \
  -e CK_DB=crawler \
  -e CK_USER=default \
  -e CK_PASS=pamirs@123 \
  ths-crawler
```

## 五、常见问题

### Q: token 获取失败？
- 检查 Node.js 是否安装: `node --version`
- 检查 jsdom 是否安装: `ls node_modules/jsdom`
- 检查 chameleon JS 文件是否存在

### Q: ClickHouse 连接失败？
- 检查网络是否能通: `telnet 100.97.74.45 9000`
- **端口必须是 9000**（原生协议），8123 是 HTTP 接口
- 检查配置是否正确
- 检查 ClickHouse 是否允许远程连接

### Q: 返回 401？
- token 已过期，会自动重试
- 如果持续 401，可能是 chameleon JS 版本过旧，需要更新

### Q: 中文乱码？
- 同花顺使用 GBK 编码，代码中已处理
- 如果 ClickHouse 中乱码，检查 CK 表字段是否为 UTF-8

### Q: 周末运行没有数据？
- A 股周末休市，同花顺 API 无数据
- 使用 `--date YYYY-MM-DD` 指定上一交易日
- 建议定时任务设在交易日 18:00 后

### Q: token 获取超时？
- jsdom 初始化需要约 15-30 秒，代码已设置 45 秒超时
- 如果持续超时，检查 Node.js 版本是否兼容（建议 16+）
