# 同花顺资金流向爬虫踩坑记录

## 2026-08-22（爬虫开发）

### 1. Token 生成进程不退出导致超时
- **现象**: `subprocess.TimeoutExpired`，token 已生成但 Python 一直等待
- **根因**: `_get_token.js` 用 `setTimeout` 输出 token 后没有调用 `process.exit(0)`，jsdom 保持事件循环活跃
- **修复**: `_get_token.js` 在 `console.log(token)` 后加 `process.exit(0)`
- **文件**: `ths/crawler/_get_token.js` 第 19-32 行
- **经验**: Node.js 脚本被 Python 调用时，输出完成后必须显式退出

### 2. 龙虎榜 HTML 的 thead/tbody 分离
- **现象**: 龙虎榜 API 返回 HTML 有数据，但解析出 0 行
- **根因**: 龙虎榜 HTML 的 `<table><thead>...</thead></table>` 和 `<div class="twrap"><table class="m-table"><tbody>...</tbody></table>` 是**两个独立的 table**
- **修复**: `parse_html_table()` 当第一个 table 只有 thead 没有 tbody 时，用 `find_next("table")` 找数据表
- **文件**: `ths/crawler/api_client.py` 第 68-101 行
- **经验**: 同花顺不同板块的 HTML 表格结构可能不同，解析要兼容

### 3. ClickHouse 表字段类型不匹配
- **现象**: `KeyError: 'sh_net'` / `'NoneType' object has no attribute 'encode'` / `required argument is not a float`
- **根因**: `northbound_flow` 表有 `sh_net/sz_net/hk_hold_net` Float64 列（非 Nullable），`time_point` 是 String（非 Nullable）
- **修复**: 
  - Float64 列用 `0.0` 而非 `None`
  - String 列用 `""` 而非 `None`
- **文件**: `ths/crawler/ck_writer.py` 第 206-237 行
- **经验**: 写入前必须 `DESCRIBE TABLE` 确认每列的 Nullable 属性

### 4. 周末休市无数据
- **现象**: 周六运行爬虫，龙虎榜返回 0 条
- **根因**: A 股周末休市，同花顺 API 没有当日数据
- **修复**: 运行时使用 `--date YYYY-MM-DD` 指定上一交易日
- **经验**: 定时任务应设在交易日 18:00 后，或用脚本判断是否交易日

## 2026-08-22（API 调研）

### 1. mitmproxy 抓不到资金流向 API（SSL Pinning）
- **现象**: 代理已设置，但 mitmproxy 只捕获到行情数据，没有资金流向相关请求
- **根因**: `data.10jqka.com.cn` 域名有 SSL Pinning，App 内置证书校验
- **尝试**: frida-server + ssl_bypass_v2.js 注入
- **结果**: 同花顺 App 有反调试保护，frida 无法附加
- **最终方案**: 放弃 App 抓包，改为分析网站 JS 源码找 API

### 2. 龙虎榜 URL 猜测错误
- **现象**: 猜测 `/market/lhb/` 返回 404
- **根因**: 路径是 `/market/longhu/`（拼音），不是 `/lhb/`

### 3. 北向资金 URL 猜测错误
- **现象**: 猜测 `/hsgt/` 返回 404
- **根因**: 正确路径是 `/hgt/hgtb/`

### 4. s.thsi.cn SSL 握手失败
- **现象**: Node.js https.get 请求 s.thsi.cn 返回 `SSL alert number 40`
- **解决**: 使用 `curl` 下载

### 5. 北向资金 AJAX 模式特殊
- **根因**: 使用 `diffRequest` 模式：`/{baseUrl}/{k1}/{v1}/{k2}/{v2}/.../ajax/1/`
- **正确 API**: `/hgt/hgtb/board/getHgtPage/ajax/1/`

### 6. GBK 编码问题
- **现象**: 中文内容乱码
- **解决**: `resp.encoding = "gbk"`

## 关键排查经验
1. **Node.js 被 Python 调用**：输出完成后必须 `process.exit(0)`
2. **同花顺路径用拼音**: `longhu` (龙虎榜), `hgt` (沪股通)
3. **同花顺 HTML 结构不统一**: 不同板块可能不同，解析要兼容
4. **ClickHouse Nullable**: 写入前 DESCRIBE TABLE 确认
5. **diffRequest 模式**: `/{base}/{k1}/{v1}/{k2}/{v2}/.../ajax/1/`
6. **定时任务设在交易日**: 周末无数据
