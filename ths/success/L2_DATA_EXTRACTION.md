## 二、帧结构总结

```
偏移 0-3:   FD FD FD FD          Magic
偏移 4-11:  "0000024b"           消息序号 (ASCII)
偏移 12-47: 帧头字段              
偏移 48-230: 基础数据区           
偏移 231+:  UTF-16LE 价格数据     ← quote 最新价
偏移 336+:  逐笔成交数据          ← tick 数据区
            (0x01=买, 0x02=卖)
```
